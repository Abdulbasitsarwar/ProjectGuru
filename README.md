# Project GURU

A web-based mentoring system designed to improve mentor-mentee matching in universities.

## Features
- User registration and login
- Questionnaire-based profiling
- Rule-based matching system
- Admin approval system
- Chat and meeting scheduling

## Technologies Used
- Python (Flask)
- SQLite
- HTML, CSS, Bootstrap

## How to Run
1. Clone the repository
2. Install dependencies
3. Run:
   python app.py
4. Open http://127.0.0.1:5000
5. For admin access http://127.0.0.1:5000/admin_login
